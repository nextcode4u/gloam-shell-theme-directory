# Folio

A botanical notebook with translucent tracing paper, folded slips and serif lettering.

![Actual Gloam renderer preview](preview.png)

The `journal` top-screen layout keeps this theme's composition. It
uses an independently illustrated icon set, full-image material surfaces and its
own focus treatment. Literata body and Kalam-Regular headings, with Latin-1 coverage.

Original cursor, confirm and back cues are included; no music loop is supplied. Native game banners keep priority over
themed fallback icons.

## Install

Requires **Gloam 1.1.0 or later**, with theme format 2 and full-image
material support. Gloam 1.2.0 is recommended to match the current previews. Gloam 1.0.0 cannot load
this revision. The [original collection](https://github.com/nextcode4u/gloam-shell-theme-directory/tree/74fd2dd/themes/folio) remains available in history.

Copy the entire `folio` folder to `/_nds/dsi-frontend/themes/folio/` on the SD
card. Back up a same-named theme first. Choose **START → Appearance → Theme**,
select Folio, press X to preview, then A to apply once ready. Reset personal wallpaper overrides to see the
supplied artwork. Other browser views and icon sizes remain selectable.
