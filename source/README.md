# Asset sources

The existing theme illustrations and independent `art/*-icons.png` masters were
created for this collection with agent assistance. The original material study
`materials/collection.png` supplies full-image glass, lacquer, velvet, paper and
leather surfaces. Morrow retains its separately authored aged parchment.
Project-held rights in these original assets are offered under CC0-1.0, as
recorded in each pack's credits. No generation prompts or drafts are distributed.

Font source pins and full notices remain separate: `config/theme-fonts.json`,
`fonts/DEJAVU-LICENSE.txt` and each runtime pack's `fonts/LICENSE.txt` describe them.
The authoritative Gloam converters prepare bounded runtime sprites and fonts.
